# Enterprise User Provisioning Architecture

## Purpose

Automate employee onboarding from HR through account provisioning.

## Systems

- HR System
- UiPath Orchestrator
- UiPath Robot
- Active Directory
- Microsoft 365
- Email Server
- SQL Database

## Workflow

HR
↓
UiPath
↓
Validation
↓
Username Generation
↓
Active Directory
↓
Microsoft 365
↓
Notifications
↓
Logging
