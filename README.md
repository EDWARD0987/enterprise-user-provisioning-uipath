
# Enterprise User Provisioning using UiPath

## Overview

This project automates the end-to-end employee onboarding process using UiPath.

## Goals

- Read employee data
- Validate employee information
- Generate usernames
- Provision Active Directory accounts
- Assign Microsoft 365 licenses
- Configure security groups
- Send welcome emails
- Generate audit logs
- Deploy through UiPath Orchestrator

## Tech Stack

- UiPath
- Microsoft 365
- Active Directory
- PowerShell
- SQL Server
- GitHub
